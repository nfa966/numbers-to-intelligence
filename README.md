## The Transformation

Traditional finance runs on **numbers, ledgers, and reports**.  
This repository explores how **AI Engineering** turns those same numbers into intelligent systems.

| From | To |
|------|-----|
| Spreadsheets & manual analysis | LLM-powered assistants & agents |
| Static reports | Dynamic RAG systems & insights |
| Rule-based processes | Adaptive AI workflows |
| Raw data | Predictive & generative intelligence |

**Senior Accountant** applying AI Engineering to real financial problems.

## Projects

| Project | What it does | Stack | Status |
|---------|--------------|-------|--------|
| Financial RAG Assistant | Answers questions from standards, policies & reports | LangChain + Chroma + LLM | Planned |
| Document Intelligence | Extracts insights & risks from invoices/reports | LLM structured output | Planned |
| Finance Research Agent | Autonomous analysis & reporting agent | LangGraph / CrewAI | Planned |
| Forecasting Engine | Revenue / cash-flow time-series models | pandas + Prophet / sklearn | Planned |
| Anomaly Detection | Flags unusual transactions | Isolation Forest + pandas | Planned |

Each project will include:
- Clear problem statement
- Runnable code + synthetic data
- Evaluation notes
- Limitations
