## Overview

This repository is a living lab where traditional finance meets modern AI.

I explore how LLMs, AI agents, data pipelines, and analytics can transform raw financial numbers into actionable intelligence — from automated analysis and forecasting to intelligent document processing and decision support.

**Focus areas:**
- LLM applications & RAG systems
- AI agents for financial analysis
- Data analytics & machine learning
- Practical automation for accounting & finance

---

## Projects

| Project | Description | Status | Tech |
|---------|-------------|--------|------|
| **Financial RAG Assistant** | Answers questions from accounting standards, policies, and financial documents | Planned | LangChain, OpenAI / open-source LLMs, Chroma |
| **Document Intelligence** | Extracts insights, summaries, and risks from invoices and reports | Planned | LLM + structured output |
| **Finance Research Agent** | Multi-step agent that analyzes data and generates reports | Planned | LangGraph / CrewAI |
| **Forecasting & Analytics** | Time-series forecasting and financial data analysis | Planned | pandas, Prophet, scikit-learn |
| **Anomaly Detection** | Identifies unusual patterns in transactions | Planned | Isolation Forest, pandas |

> Projects will be added progressively. Each will include a clear README, sample data (synthetic only), and runnable code.
